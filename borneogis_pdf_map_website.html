FAQ

Pertanyaan yang sering ditanyakan

Avenza Maps memiliki batas 3 peta gratis dan membutuhkan akun. BorneoGIS PDF Map sepenuhnya gratis, bebas akun, bebas iklan, dan tidak ada batasan jumlah peta. Khusus dirancang untuk kebutuhan lapangan di Kalimantan dan Indonesia.
Mendukung GeoPDF standar OGC (GPTS/LPTS array), GeoPDF gaya USGS dengan XMP viewport metadata, dan GeoPDF gaya ESRI dengan LGI dict. File dari QGIS, ArcGIS, Global Mapper, dan software GIS lainnya umumnya kompatibel.
Ya. PDF biasa bisa dibuka dan ditampilkan, tetapi fitur overlay GPS tidak tersedia karena tidak ada data georeferencing. Aplikasi akan menampilkan peringatan "No georef" di header viewer.
Konversi UTM menggunakan datum WGS84, zona dihitung otomatis berdasarkan koordinat GPS. Untuk Kalimantan Timur, umumnya berada di zona 50S atau 50N tergantung posisi relatif terhadap ekuator.
Tidak sama sekali setelah instalasi. Semua fungsi — membuka peta, GPS, kompas, konversi koordinat — berjalan 100% offline. Aplikasi tidak melakukan koneksi internet dalam kondisi apapun.
Android 5.0 (API level 21) atau lebih baru. Untuk performa optimal, direkomendasikan Android 8.0+ dengan RAM minimal 2GB. Sensor GPS dan magnetometer dibutuhkan untuk fitur kompas (opsional).
About

Dibuat oleh praktisi GIS lapangan

BorneoGIS PDF Map lahir dari kebutuhan nyata survei lapangan di wilayah terpencil Kalimantan, di mana koneksi internet tidak tersedia dan aplikasi berbayar tidak terjangkau.

Dibangun dengan Flutter untuk performa native Android, menggunakan library PDF dan GPS terpercaya, serta konversi UTM bawaan tanpa dependensi eksternal.
